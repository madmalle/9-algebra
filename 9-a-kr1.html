Задание 1. Линейные уравнения
Решите уравнения:
а) 2(x - 13) = x + 13
б) 3(x + 1) - 2(x - 1) = 4
Решение:
а) Раскроем скобки в левой части уравнения:
2x - 26 = x + 13
Перенесём слагаемые с переменной x в левую часть, а числа — в правую:
2x - x = 13 + 26 ⟹ x = 39
б) Раскроем скобки в левой части (учитывая знак минус перед второй скобкой):
3x + 3 - 2x + 2 = 4
Приведём подобные слагаемые:
x + 5 = 4 ⟹ x = 4 - 5 ⟹ x = -1
Ответ: а) 39; б) -1
Задание 2. Квадратное уравнение
Решите уравнение: x² - 6x - 16 = 0.
Если уравнение имеет более одного корня, в ответ запишите меньший из корней.
Решение:
Способ 1 (через дискриминант)
Выпишем коэффициенты уравнения:
a = 1,   b = -6,   c = -16
Найдем дискриминант по формуле D = b² - 4ac:
D = (-6)² - 4 · 1 · (-16) = 36 + 64 = 100 = 10²
Найдем корни уравнения:
x₁ = -b + √D2a = 6 + 102 = 162 = 8

x₂ = -b - √D2a = 6 - 102 = -42 = -2
Способ 2 (по теореме Виета)
По теореме Виета для приведённого квадратного уравнения составляем систему:
{
x₁ + x₂ = -b = 6
x₁ · x₂ = c = -16
Подбором находим корни: x₁ = 8, x₂ = -2.
Сравним полученные корни: -2 < 8. Меньший из корней равен -2.
Ответ: -2
Задание 3. Биквадратное уравнение
Решите уравнение: (x + 5)⁴ + (x + 5)² - 12 = 0
Решение:
Введём новую переменную: пусть t = (x + 5)², причём t ≥ 0.
Подставим t в исходное уравнение:
t² + t - 12 = 0
Найдем корни квадратного уравнения относительно t:
t₁ = 3,   t₂ = -4
Выполним обратную замену:
1) При t = 3:
(x + 5)² = 3 ⟹ x + 5 = ±√3 ⟹ x = -5 ± √3

2) При t = -4:
(x + 5)² = -4 — корней нет (так как квадрат числа не может быть отрицательным).
Ответ: -5 - √3; -5 + √3
Задание 4. Уравнение 3 степени
Решите уравнение: x³ + 5x² - 16x - 80 = 0
Решение:
Сгруппируем слагаемые попарно:
(x³ + 5x²) - (16x + 80) = 0
Вынесем общие множители за скобки в каждой группе:
x²(x + 5) - 16(x + 5) = 0
Вынесем общий множитель (x + 5) за скобку:
(x + 5)(x² - 16) = 0
Произведение равно нулю, когда хотя бы один из множителей равен нулю:
1) x + 5 = 0 ⟹ x = -5
2) x² - 16 = 0 — решим как неполное квадратное уравнение:
x² = 16 ⟹ x = ±4
Ответ: -5; -4; 4
Задание 5. Дробно-рациональное уравнение
Решите уравнение:
3xx + 1 + 2x = 2x + 5x² + x
Решение:
Запишем знаменатель правой части в виде произведения: x² + x = x(x + 1).
Область допустимых значений (ОДЗ):
Знаменатели не должны быть равны нулю:
x ≠ 0 и x + 1 ≠ 0 ⟹ x ≠ -1.
Умножим обе части уравнения на общий знаменатель x(x + 1):
3x · x + 2(x + 1) = 2x + 5
Раскроем скобки и приведём подобные слагаемые:
3x² + 2x + 2 = 2x + 5 ⟹ 3x² - 3 = 0 ⟹ 3(x² - 1) = 0
x² = 1 ⟹ x = 1 или x = -1
Проверим найденные корни по ОДЗ:
• Значение x = -1 — не подходит по ОДЗ.
• Значение x = 1 — подходит по ОДЗ.
Ответ: 1
